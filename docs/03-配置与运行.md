# 配置与运行

## 1. 静态配置文件

主配置文件是 [config/conf.yaml](../config/conf.yaml)。

当前默认内容：

```yaml
paths:
  redis_host_config_path: "setup/redis/config"
  redis_config_path: "/data/redis/config"
  redis_host_data_path: "setup/redis/data"
  redis_config_data_path: "/data/redis/data"
  runtime_state_dir: "runtime"

kubernetes:
  kube_config_path: ""
  namespace: "default"
  base_node_port: 30000

configs:
  save_file_name: "run_time_config.yaml"
  container_info_file_name: "containers.json"
  image_name: "myredis"
  redis_port: 6379
```

## 2. 配置项含义

### `paths.redis_host_config_path`

- 宿主机上的 Redis 配置目录
- 用于生成 K8s ConfigMap（将 `redis.conf` 挂载到容器内）

### `paths.redis_config_path`

- 容器内 Redis 配置目录
- 启动命令里会拼出 `redis.conf` 路径

### `paths.redis_host_data_path`

- 宿主机上的 Redis 数据目录（用于持久化，当前未在 K8s 方案中使用）

### `paths.redis_config_data_path`

- 容器内 Redis 数据目录

### `paths.runtime_state_dir`

- 运行时状态文件（容器信息、配置快照）的存放根目录
- 每个集群的状态文件会按 `<runtime_state_dir>/<clusterName>/` 存放

### `kubernetes.kube_config_path`

- Kubeconfig 文件路径
- 留空时自动尝试：`$KUBECONFIG` 环境变量 → `~/.kube/config` → InClusterConfig

### `kubernetes.namespace`

- K8s Namespace，默认为 `default`

### `kubernetes.base_node_port`

- NodePort 起始端口（当前未强制使用，NodePort 由 K8s 自动分配）

### `configs.save_file_name`

- 集群创建时保存的运行时配置文件名

### `configs.container_info_file_name`

- 容器/Pod 信息 JSON 文件名

### `configs.image_name`

- Redis 容器镜像名

### `configs.redis_port`

- Redis 容器端口，默认为 6379

## 3. 环境变量覆盖

所有配置项均可通过环境变量覆盖：

| 配置项 | 环境变量 |
|--------|----------|
| `paths.redis_host_config_path` | `REDIS_HOST_CONFIG_PATH` |
| `paths.redis_config_path` | `REDIS_CONFIG_PATH` |
| `paths.redis_host_data_path` | `REDIS_HOST_DATA_PATH` |
| `paths.redis_config_data_path` | `REDIS_CONFIG_DATA_PATH` |
| `paths.runtime_state_dir` | `CLUSTER_STATE_DIR` |
| `kubernetes.kube_config_path` | `KUBECONFIG` |
| `kubernetes.namespace` | `KUBE_NAMESPACE` |
| `kubernetes.base_node_port` | `BASE_NODE_PORT` |
| `configs.save_file_name` | `CLUSTER_SAVE_FILE_NAME` |
| `configs.container_info_file_name` | `CLUSTER_CONTAINER_INFO_FILE` |
| `configs.image_name` | `CLUSTER_IMAGE_NAME` |
| `configs.redis_port` | `CLUSTER_REDIS_PORT` |

## 4. 运行时状态文件

每次创建集群时，会在运行时状态目录下生成：

```
<runtime_state_dir>/<clusterName>/
├── containers.json          # Pod/Service 信息
└── run_time_config.yaml     # 集群配置快照（nodes-per-shard、port 等）
```

删除集群时会自动清理这些文件。

## 5. 前置条件

- 可访问的 Kubernetes 集群（kubeconfig 或集群内运行）
- Redis 镜像已构建或可从 registry 拉取
- `redis.conf` 已放置在 `paths.redis_host_config_path` 下
