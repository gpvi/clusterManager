# 配置与运行

## 1. 静态配置文件

主配置文件是 [config/conf.yaml](../config/conf.yaml)。

```yaml
backend: "k8s"                 # 默认后端
db_path: ""                    # SQLite 路径（空则自动 runtime/cluster.db）
containerd_socket: ""          # containerd socket（空则自动检测）

paths:
  redis_host_config_path: "setup/redis/config"
  redis_config_path: "/data/redis/config"
  redis_host_data_path: "setup/redis/data"
  redis_config_data_path: "/data/redis/data"
  runtime_state_dir: "runtime"

kubernetes:
  kube_config_path: ""
  namespace: "default"
  base_node_port: 30000

configs:
  save_file_name: "run_time_config.yaml"
  container_info_file_name: "containers.json"
  image_name: "redis:7-alpine"
  redis_port: 6379
```

## 2. 配置项说明

### 顶层

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `backend` | 默认后端：`k8s` / `podman` / `containerd` | `k8s` |
| `db_path` | SQLite 数据库路径，空则使用 `runtime/cluster.db` | `""` |
| `containerd_socket` | containerd socket 路径 | 自动检测（Linux: `/run/containerd/containerd.sock`, Windows: `\\.\pipe\containerd-containerd`） |

### paths

| 配置项 | 说明 |
|--------|------|
| `redis_host_config_path` | 宿主机上的 Redis 配置目录 |
| `redis_config_path` | 容器内 Redis 配置挂载路径 |
| `redis_host_data_path` | 宿主机 Redis 数据目录 |
| `redis_config_data_path` | 容器内 Redis 数据挂载路径 |
| `runtime_state_dir` | 运行时状态文件根目录 |

### kubernetes（仅 K8s 后端）

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `kube_config_path` | kubeconfig 路径 | `$KUBECONFIG` → `~/.kube/config` → InCluster |
| `namespace` | K8s namespace | `default` |
| `base_node_port` | NodePort 起始端口 | `30000` |

### configs

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `save_file_name` | 运行时配置文件名 | `run_time_config.yaml` |
| `container_info_file_name` | 容器信息 JSON 文件 | `containers.json` |
| `image_name` | Redis 镜像 | `redis:7-alpine` |
| `redis_port` | Redis 容器端口 | `6379` |

## 3. 环境变量覆盖

所有配置项均可通过环境变量覆盖：

| 配置项 | 环境变量 |
|--------|----------|
| `backend` | `CLUSTER_BACKEND` |
| `db_path` | `CLUSTER_DB_PATH` |
| `containerd_socket` | `CLUSTER_CONTAINERD_SOCKET` |
| `paths.redis_host_config_path` | `REDIS_HOST_CONFIG_PATH` |
| `paths.redis_config_path` | `REDIS_CONFIG_PATH` |
| `paths.redis_host_data_path` | `REDIS_HOST_DATA_PATH` |
| `paths.redis_config_data_path` | `REDIS_CONFIG_DATA_PATH` |
| `paths.runtime_state_dir` | `CLUSTER_STATE_DIR` |
| `kubernetes.kube_config_path` | `KUBECONFIG` |
| `kubernetes.namespace` | `KUBE_NAMESPACE` |
| `kubernetes.base_node_port` | `BASE_NODE_PORT` |
| `configs.save_file_name` | `CLUSTER_SAVE_FILE_NAME` |
| `configs.container_info_file_name` | `CLUSTER_CONTAINER_INFO_FILE` |
| `configs.image_name` | `CLUSTER_IMAGE_NAME` |
| `configs.redis_port` | `CLUSTER_REDIS_PORT` |

环境变量优先级高于配置文件。

## 4. 运行时状态

### 文件结构

```
<runtime_state_dir>/
├── cluster.db                      # SQLite 数据库（持久化状态与审计日志）
└── <clusterName>/
    ├── containers.json             # 容器信息
    └── run_time_config.yaml        # 集群配置快照
```

### SQLite 表结构

- **clusters** — 集群元数据（名称、后端、shard 数、状态、时间戳）
- **containers** — 容器实例（名称、ID、IP/端口、角色、状态）
- **operations** — 操作审计日志（操作类型、详情、成功/失败、时间戳）

## 5. 前置条件

| 后端 | 前置条件 |
|------|----------|
| Podman | `podman` CLI 可用，`podman machine` 运行中（Windows） |
| Kubernetes | 可访问的 K8s 集群，`kubectl` / kubeconfig 可用 |
| Containerd | containerd 服务运行中，socket 可访问，编译时加 `-tags containerd` |

所有后端均需：`redis.conf` 放置在 `paths.redis_host_config_path` 下。
