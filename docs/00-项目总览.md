# 项目总览

## 1. 项目是什么

`clusterManager` 是一个基于 Go 实现的 Redis Cluster 命令行管理工具，当前主要能力有三类：

- 创建集群
- 删除集群
- 扩容集群

项目通过 **Cobra** 提供 CLI，通过 **Kubernetes client-go** 创建和管理 Redis Pod/Service/ConfigMap，通过 **go-redis** 调用 Redis Cluster 命令完成节点发现、主从配置和槽位分配/迁移。

## 2. 当前实现目标

从代码实现看，这个项目的目标不是做通用云平台，而是面向单机 K8s 环境，自动完成以下事情：

1. 在 K8s 集群中创建一批 Redis Pod（带 NodePort Service）
2. 让这些节点互相 `CLUSTER MEET`
3. 设置 master / replica 关系
4. 给 master 分配 16384 个 slot
5. 在扩容时新增节点并迁移 slot

## 3. 命令入口

程序入口是 [main.go](../main.go)，实际命令定义在 `cmd/`：

- `cluster create`
- `cluster delete`
- `cluster scale`

## 4. 关键依赖

- **Kubernetes client-go** — Pod/Service/ConfigMap 生命周期
- **go-redis** — Redis Cluster 管理命令
- **Cobra** — CLI 框架
- **YAML v2** — 配置文件解析

## 5. 历史演进

- 初始版本基于 Podman API 管理容器
- `feature/k8s-rewrite` 分支完全重写为 Kubernetes 原生方案
- 已消除全部包级全局变量（`RuntimeConfig` 依赖注入）
- 已修复多轮代码审查发现的逻辑错误（slot 验证、SETSLOT 目标、连接泄漏等）
