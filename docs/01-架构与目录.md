# 架构与目录

## 模块信息

- **Module**: `redisClusterManager` (Go 1.25)
- **二进制**: `cluster` (CLI)
- **后端**: Podman / Containerd

## 三大模块

```
┌──────────────────────────────────────────────┐
│                  cluster                      │
│          Redis 集群编排 + CLI                  │
│  cluster/{cmd,model,config,utils,proto}/ scripts/   │
│         Podman / Containerd 后端              │
├──────────────────────────────────────────────┤
│                  cache                        │
│            分布式内存缓存 (GeeCache)            │
│  LRU+TTL / 一致性哈希 / gRPC P2P / gossip     │
│        热点检测 / single-flight / 限流         │
├──────────────────────────────────────────────┤
│                  agent                        │
│           Python AI Agent (LangGraph)          │
│       GPT-4o + 6 tools → clusterd gRPC        │
│         FastAPI server (port 8000)             │
└──────────────────────────────────────────────┘
```

## 模块边界

### cluster — 集群编排核心

| 层级 | 目录 | 职责 |
|------|------|------|
| CLI 入口 | `cluster/cmd/` | `cluster create/delete/scale/cache` 子命令 |
| 业务逻辑 | `cluster/model/` | PodManager 接口, ClusterManager, 后端实现, 配置, SQLite |
| 工具 | `cluster/utils/` | YAML 读写, 字符串转换, Redis 命令执行 |
| 协议 | `cluster/proto/` | gRPC 定义 (cluster 管理 + cache 对等) |
| 配置 | `cluster/config/` `configs/` | YAML 配置, Redis 模板, Dockerfile |
| 脚本 | `scripts/` | 构建脚本 |

### cache — 分布式缓存

| 层级 | 目录 | 职责 |
|------|------|------|
| 核心 | `cache/geecache.go` | Group (缓存命名空间), Get 读取路径 |
| LRU | `cache/lru/` | LRU 淘汰算法 |
| 哈希 | `cache/consistenthash/` | 一致性哈希环 |
| 对等 | `cache/peer/` | memberlist gossip + gRPC 传输 + TLS |
| 热点 | `cache/hotkey.go` | 热点 key 检测与复制 |
| 限流 | `cache/ratelimit.go` | DB 回源 token bucket |
| 失效 | `cache/invalidator.go` | Slot 迁移缓存失效 |
| 回源 | `cache/redis_getter.go` | Redis L2 回源 |
| 合并 | `cache/singleflight/` | 请求去重 |

### agent — AI 运维代理

| 层级 | 文件 | 职责 |
|------|------|------|
| 服务 | `agent/src/server.py` | FastAPI, `/chat` `/health` (port 8000) |
| 工具 | `agent/src/tools.py` | 6 LangChain 工具 → clusterd gRPC |
| 流程 | `agent/src/workflows.py` | LangGraph StateGraph (GPT-4o + MemorySaver) |
| 协议 | `agent/src/stub/` | Python gRPC stubs |

**依赖方向**: `agent` → gRPC → `clusterd` → `PodManager` ← `cache` 独立运行

## 核心接口

### PodManager
```go
type PodManager interface {
    CreatePods(ctx, nodeNum, clusterName) error
    ListPodsByCluster(ctx, clusterName) error
    DeleteResources(ctx, clusterName) error
    HasCluster(clusterName) bool
    CountByCluster(clusterName) int
    GetNodes() []*RuntimeNode
    GetNodeByIP(ip) *RuntimeNode
    GetNodeByHost(host) *RuntimeNode
    GetNodeCount() int
}
```

实现: `PodmanNodeManager` / `ContainerdNodeManager` (build tag: `containerd`)

### CacheInvalidator
```go
type CacheInvalidator interface {
    InvalidateSlots(start, end int)
}
```

## 核心流程

### 创建集群
```
NewNodeManager(cfg) → PodmanNodeManager
CreateClusterAction()
  CreateSource()       → CreatePods (并行)
  Bootstrap()
    MeetNodes()        → CLUSTER MEET (hostname 或 IP)
    UpdateAfterMeet()  → CLUSTER NODES 解析拓扑
    SetAllNodeRole()   → master/slave + CLUSTER REPLICATE
    AllocateSlots()    → 16384 slots 均分
  Store 持久化         → SQLite
```

### 扩容集群
```
CreateSource()          → 新 Pods
MeetNodes()             → 加入集群
SetNodeAsSlave()        → 设为 slave
MigratesSlotsToEmptyNode()
  16 workers 并发
  ┌─ 空 slot: 跳过
  ├─ 少量 key: 单次 MIGRATE
  ├─ 批量: 分片 pipeline
  └─ 大 key (>10MB): COPY+DELETE
CacheInvalidator.InvalidateSlots()
```

### Cache 读取路径
```
Get(key)
  hotTracker.Record()       → 热点统计
  if cacheDirty → purge()   → 迁移后清除
  LRU hit → return          → ~1μs
  load(key)
    singleFlight.Do()
      PickPeerWithFallback  → 主→副→...
      fetchFromPeer (gRPC)  → 远程命中
      getLocally()
        dbLimiter.Wait()    → 限流
        getter.Get(key)     → Redis/DB 回源
      replicateToSecondaries
      replicateIfHot
```

## 配置

```yaml
# config/conf.yaml
backend: "podman"             # podman | containerd
db_path: ""                   # SQLite 路径

paths:
  redis_host_config_path: "configs"
  redis_config_path: "/data/redis/config"
  redis_host_data_path: "configs"
  redis_config_data_path: "/data/redis/data"
  runtime_state_dir: "runtime"

configs:
  save_file_name: "run_time_config.yaml"
  image_name: "redis:7-alpine"
  redis_port: 6379

cache:                        # 缓存子系统
  enabled: false
  max_bytes: 1073741824
  ttl: 3600
  server_port: 8001
  gossip_port: 9001
  ...

dns:                          # DNS 寻址
  enabled: false
  domain: "svc.cluster.local"
  naming_template: "{{.ClusterName}}-redis-{{.Index}}..."
```

## SQLite 数据模型

```sql
clusters (name, backend, shards, nodes_per_shard, redis_port, image, status)
containers (name, cluster_name, container_id, host_ip, host_port,
            container_ip, container_port, role, status, node_index, hostname)
operations (id, cluster_name, operation, detail, success, created_at)
```
