# 架构与目录

## 模块信息

- **Module**: `redisClusterManager` (Go 1.25)
- **二进制**: `cluster` (CLI) / `clusterd` (gRPC) / `cluster-operator` (K8s Operator)

## 入口与运行模式

```
                    main.go (CLI)
                   /    |    \
                  /     |     \
           create  delete  scale  cache      ← Cobra 子命令
                  \     |     /
                   model/ (核心逻辑)
                        |
            +-----------+-----------+
            |           |           |
          k8s        podman    containerd    ← 三后端
```

| 入口 | 文件 | 说明 |
|------|------|------|
| **CLI** | `main.go` | `cluster create/delete/scale/cache` 命令行管理 |
| **gRPC 服务** | `cmd/clusterd/main.go` | 端口 50051，提供 8 个 RPC API |
| **K8s Operator** | `cmd/operator/main.go` | 通过 CRD 调和 RedisCluster 资源 |
| **AI Agent** | `agent/src/server.py` | FastAPI + LangGraph + GPT-4o，调用 clusterd gRPC |

## 核心接口

### PodManager (model/interfaces.go)
```go
type PodManager interface {
    CreatePods(ctx, nodeNum, clusterName) error
    ListPodsByCluster(ctx, clusterName) error
    DeleteResources(ctx, clusterName) error
    HasCluster(clusterName) bool
    CountByCluster(clusterName) int
    GetNodes() []*RuntimeNode
    GetNodeByIP(ip) *RuntimeNode
    GetNodeByHost(host) *RuntimeNode   // DNS 支持
    GetNodeCount() int
    SaveToJSON(filename) error
}
```

实现：`K8sNodeManager` / `PodmanNodeManager` / `ContainerdNodeManager`（编译标签 `containerd`）

### CacheInvalidator (model/interfaces.go)
```go
type CacheInvalidator interface {
    InvalidateSlots(start, end int)
}
```
实现：`cache.SlotInvalidator` — slot 迁移后清除缓存脏数据

## 关键数据结构

### RuntimeNode — 容器/节点运行时视图
```go
type RuntimeNode struct {
    HostIP, HostPort        // 管理端可达 (127.0.0.1:NodePort)
    ConIp, ConPort          // 容器内 Redis 地址
    Hostname                // DNS 名称 (dns.enabled=true)
    Name, ID, ClusterName
    Address  NodeAddress    // {ClusterAddr, ClientAddr}
}
func (n *RuntimeNode) ClusterMeetAddr() string  // hostname:port 或 ConIp:ConPort
func (n *RuntimeNode) ClientConnAddr() string   // 127.0.0.1:HostPort
```

### ClusterNode — Redis 集群拓扑视图
```go
type ClusterNode struct {
    ID, IP, Port, NodeType  // master|slave
    MasterID, LinkState
    Slots    []SlotRange    // 槽位区间 [{Start,End}]
    SlotsNum int
}
```

### ClusterManager — 集群编排器
```go
type ClusterManager struct {
    EmptyMasters      []*ClusterNode       // 空主节点列表
    IDToClusterNode   map[string]*ClusterNode
    IPToClusterID     map[string]string
    MasterToSlave     map[string][]string
    MasterIDs         []string
    nodeManager       PodManager           // 后端抽象
    cacheInvalidator  CacheInvalidator     // 缓存失效
}
```

## 核心流程

### 创建集群
```
NewNodeManager(cfg)       → 后端工厂
CreateClusterAction()     → 验证参数
  CreateSource()          → 后端 CreatePods (并行)
  Bootstrap()
    MeetNodes()           → CLUSTER MEET (hostname 或 IP)
    UpdateAfterMeet()     → CLUSTER NODES 解析拓扑
    SetAllNodeRole()      → master/slave 分配 + CLUSTER REPLICATE
    AllocateSlots()       → 16384 slots 均分给 master
  Store 持久化            → SQLite clusters/containers 表
```

### 扩容集群
```
CreateSource()            → 创建新 Pods
MeetNodes()               → MEET 新节点入集群
SetNodeAsSlave()          → 新节点设为 slave
MigratesSlotsToEmptyNode()
  16 workers 并发迁移
  ┌─ 空 slot: 即时跳过
  ├─ 少量 key: 单次 MIGRATE
  ├─ 批量 key: 分片 MIGRATE (pipeline)
  └─ 大 key (>10MB): COPY+DELETE
CacheInvalidator.InvalidateSlots() → 清除脏缓存
```

### 删除集群
```
DeleteAllContainers()
  后端 DeleteResources  (删除 Pods/Services/ConfigMaps)
  Store 清理             (删除 SQLite 记录)
  删除运行时状态文件
```

### Cache Node 启动
```
cache.Run(ctx, cfg)
  createRegistry()        → memberlist gossip 集群
  createGroup()           → 缓存命名空间 (Getter → Redis/DB)
  startGrpcServer()       → gRPC 对等通信
  startCacheHTTPServer()  → 健康检查 (port+100)
  startAPIServer()        → HTTP API 网关 (:9999, 可选)
```

### Cache 读取路径
```
Get(key)
  hotTracker.Record(key)        → 热点统计
  if cacheDirty → purge()       → 迁移后清除脏数据
  local LRU hit → return        → ~1μs
  load(key)
    singleFlight.Do(key, fn)
      PickPeerWithFallback()    → 一致性哈希: 主→副→...
      fetchFromPeer (gRPC)      → 远程节点命中
      getLocally()
        dbLimiter.Wait()        → 限流
        getter.Get(key)         → Redis/DB 回源
      replicateToSecondaries    → 副本复制
      replicateIfHot            → 热 key 复制
```

## 数据模型 (SQLite)

```sql
-- 集群记录
CREATE TABLE clusters (
    name TEXT PRIMARY KEY,
    backend TEXT, shards INT, nodes_per_shard INT,
    redis_port INT, image TEXT, status TEXT,
    created_at TEXT, updated_at TEXT
);

-- 容器记录 (含 DNS hostname)
CREATE TABLE containers (
    name TEXT PRIMARY KEY,
    cluster_name TEXT, container_id TEXT,
    host_ip TEXT, host_port INT, container_ip TEXT, container_port INT,
    role TEXT, status TEXT, node_index INT,
    hostname TEXT   -- DNS 名称
);

-- 操作日志
CREATE TABLE operations (
    id INTEGER PRIMARY KEY,
    cluster_name TEXT, operation TEXT, detail TEXT,
    success BOOLEAN, created_at TEXT
);
```

## 配置结构

```yaml
# config/conf.yaml
backend: "k8s" | "podman" | "containerd"
db_path: ""
containerd_socket: ""

paths:        # 路径配置
  redis_host_config_path: "configs"
  redis_config_path: "/data/redis/config"
  redis_host_data_path: "setup/redis/data"
  redis_config_data_path: "/data/redis/data"
  runtime_state_dir: "runtime"

kubernetes:   # K8s 配置
  kube_config_path: ""
  namespace: "default"
  base_node_port: 30000

configs:      # 容器配置
  save_file_name: "run_time_config.yaml"
  container_info_file_name: "containers.json"
  image_name: "redis:7-alpine"
  redis_port: 6379

cache:        # 缓存子系统 (16 字段)
  enabled: false
  max_bytes: 1073741824    # 1GB
  ttl: 3600                # 默认 TTL (秒)
  hot_key_threshold: 100   # 热点阈值 (10s窗口)
  hot_replicas: 2          # 热 key 额外副本
  db_rate_limit: 200       # DB 回源限流 (QPS)
  server_ip: "0.0.0.0"
  server_port: 8001        # gRPC 缓存端口
  gossip_port: 9001        # memberlist 端口
  api_gateway: false       # HTTP API 网关
  cache_group_name: "default"
  seeds: []                # 种子节点
  tls_mode: "insecure"     # insecure | server | mutual

dns:          # DNS 寻址 (3 字段)
  enabled: false
  domain: "svc.cluster.local"
  naming_template: "{{.ClusterName}}-redis-{{.Index}}.{{.ClusterName}}-svc.{{.Namespace}}"
```
