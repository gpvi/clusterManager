# 架构与目录

## 1. 目录结构

```text
clusterManager/
├── cmd/              CLI 命令定义
│   ├── root.go      根命令与帮助
│   ├── create.go    创建命令
│   ├── delete.go    删除命令
│   └── scale.go     扩容命令
├── config/           静态配置文件
│   └── conf.yaml
├── docs/             文档
├── scripts/          构建、测试脚本
├── model/            核心业务逻辑
│   ├── config.go        配置读取与 RuntimeConfig 定义
│   ├── k8s_client.go    K8s clientset 构建
│   ├── k8s_manager.go   Pod/Service/ConfigMap 生命周期
│   ├── cluster_manager.go  Redis Cluster 编排（meet、主从、slot）
│   ├── cluster_node.go  ClusterNode 结构体与 slot 范围解析
│   ├── create_cluster.go 创建流程编排
│   ├── delete_cluster.go 删除流程编排
│   └── scale_cluster.go  扩容流程编排
├── utils/            工具函数（YAML、端口解析等）
├── main.go           入口：初始化配置 → 启动 CLI
├── Makefile          构建/测试快捷命令
└── go.mod            Go 模块定义
```

## 2. 分层职责

### `main.go`

- 调用 `model.InitConfig()` 初始化配置
- 将 `*RuntimeConfig` 注入 cmd 层
- 执行 Cobra 根命令

### `cmd/`

负责解析用户输入并调用 `model` 层 action 函数：

- 接收 `*RuntimeConfig`（通过 `SetConfig`）
- 处理 CLI 参数（`--shards`、`--nodes-per-shard`、`--clusterName`、`--port` 等）
- 将参数传递给 action 函数

### `model/`

核心业务逻辑，分三层：

**配置层** (`config.go`)
- `Config` 结构体映射 YAML 配置
- `RuntimeConfig` 结构体持有运行时配置（DI 注入）
- 路径解析、环境变量覆盖

**K8s 资源层** (`k8s_client.go` + `k8s_manager.go`)
- `NewK8sClientset(kubeConfigPath)` — 构建 K8s 客户端
- `K8sNodeManager` — 管理 Pod/Service/ConfigMap
  - `CreatePods` — 并行创建 Pod + 等待就绪
  - `DeleteResources` — 清理资源
  - `ListPodsByCluster` — 列出已有 Pod
  - `CreateRedisClient` — 创建 Redis 客户端

**集群编排层** (`cluster_manager.go` + action 文件)
- `ClusterManager` — 持有 Redis 集群状态（节点列表、主从关系、槽位分配）
- action 函数 — 编排完整流程：
  - `CreateClusterAction` — 创建 Pods → MEET → 主从分配 → slot 分配
  - `DeleteAllContainers` — 清理 K8s 资源 + 状态文件
  - `ScaleClusterAction` — 扩容 Pods → MEET → 主从 → slot 迁移

### `utils/`

纯工具函数，无外部依赖（除 go-redis、yaml）：
- `ParseIPPort` / `StringToUint16` — 字符串解析
- `ReadFromYAMLFile` / `WriteToYAMLFile` — 文件读写
- `ExecuteClusterCommand` — Redis 命令封装

## 3. 核心数据流

```
CLI 输入
  → cmd 层解析参数
    → model action 函数（CreateClusterAction / DeleteAllContainers / ScaleClusterAction）
      → InitConfig() 获取 RuntimeConfig
      → NewK8sClientset(kubeConfigPath) 获取 clientset
      → NewK8sNodeManager(clientset, namespace, config) 创建节点管理器
      → NewClusterManager(nodesPerShard, nodeManager) 创建集群管理器
      → ClusterManager 方法执行 Redis Cluster 编排
      → 保存状态文件
```

## 4. 关键对象

### RuntimeConfig

```go
type RuntimeConfig struct {
    KubeConfigPath      string
    KubeNamespace       string
    RedisContainerPort  uint16
    ImageName           string
    // ... 路径、状态文件等配置
}
```

通过 `main.go` 初始化一次，注入各层。

### K8sNodeManager

```go
type K8sNodeManager struct {
    clientset kubernetes.Interface
    namespace string
    config    *RuntimeConfig
    Nodes     []*RuntimeNode   // 所有已知节点
    IPToNode  map[string]*RuntimeNode
}
```

### ClusterManager

```go
type ClusterManager struct {
    nodeManager     *K8sNodeManager
    NodesPerShard   int
    ClusterNodeList []*ClusterNode   // Redis CLUSTER NODES 视图
    MasterIDs       []string
    MasterToSlave   map[string][]string
    // ...
}
```
