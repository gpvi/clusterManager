# 开发与测试指南

## 1. 开发环境

推荐环境：

- Go 1.23 或兼容版本
- 可访问的 Kubernetes 集群（minikube、kind、Docker Desktop 等）
- `redis.conf` 放在 `setup/redis/config/` 下

## 2. 构建

```powershell
# 直接构建
go build -o cluster .

# 或使用 Makefile
make build
```

## 3. 运行测试

### 单元测试

```powershell
# 运行所有单元测试
go test ./model/... -run "TestParse|TestResolve|TestContainer"
go test ./utils/...

# 或使用 Makefile
make test
```

### 集成测试

集成测试需要真实的 K8s 集群和 `integration` build tag：

```powershell
$env:CLUSTER_RUN_INTEGRATION_TESTS = "1"
go test -tags integration ./model/...
```

集成测试包含：
- `TestCreation` — 完整创建流程
- `TestAddAction` — 扩容流程
- `TestDeleteAllAction` — 删除流程
- `TestConfig` — 配置文件读取

## 4. 代码约定

- 配置通过 `*RuntimeConfig` 依赖注入，不再使用包级全局变量
- `CreateRedisClient` 返回 `(*redis.Client, error)`（不调用 `log.Fatal`）
- 新解析逻辑应提取为无副作用的纯函数以便单元测试（参考 `parseClusterNodeLines`）
- 集群操作失败时自动回滚 K8s 资源

## 5. 目录结构

```text
clusterManager/
├── cmd/              CLI 命令定义（cobra）
│   ├── root.go      根命令
│   ├── create.go    创建命令
│   ├── delete.go    删除命令
│   └── scale.go     扩容命令
├── config/           静态配置文件
│   └── conf.yaml
├── model/            核心业务逻辑
│   ├── config.go        配置读取与 RuntimeConfig
│   ├── k8s_client.go    K8s clientset 构建
│   ├── k8s_manager.go   Pod/Service/ConfigMap 管理
│   ├── cluster_manager.go  Redis Cluster 编排
│   ├── cluster_node.go  ClusterNode 定义与 slot 解析
│   ├── create_cluster.go 创建流程
│   ├── delete_cluster.go 删除流程
│   └── scale_cluster.go  扩容流程
├── utils/            工具函数
├── scripts/          构建/测试脚本
├── docs/             文档
├── setup/            Redis 配置文件
├── main.go           程序入口
└── Makefile          构建快捷命令
```

## 6. 静态检查

```powershell

```
