# 当前状态与问题清单

## 1. 当前项目状态

项目已从单一 K8s 后端重构为**多后端架构**（`feature/k8s-rewrite` 分支）。

### 已就绪

| 类别 | 内容 |
|------|------|
| 多后端 | K8s（K8s API）、Podman（CLI，已实机验证）、Containerd（Go API，build tag） |
| CLI | create / delete / scale，`--backend` / `--containerd-socket` / `--db` 全局参数 |
| 接口设计 | `PodManager` 接口（9 方法），工厂模式 `NewNodeManager(cfg)` |
| 集群生命周期 | 创建（MEET → 主从 → slot）、扩容（并发迁移 16 workers + 进度）、删除 |
| Slot 迁移优化 | chunk 分片 + big key 检测 + COPY 模式 + EXISTS 预检 |
| IP 模型 | `NodeAddress` 类型（ClusterAddr / ClientAddr），消除 `127.0.0.1` 硬编码 |
| 持久化 | SQLite（clusters / containers / operations 三表），操作审计日志 |
| 配置 | YAML + 环境变量双通道，16 个配置项全覆盖 |
| 测试 | model / config / controller / utils 包测试通过 |

### 后端对比

| 特性 | K8s | Podman | Containerd |
|------|-----|--------|------------|
| 驱动方式 | K8s API | podman CLI | containerd Go API |
| 网络模型 | PodIP + NodePort | bridge IP + port mapping | host 网络 + 顺序端口 |
| 编译要求 | 默认 | 默认 | `-tags containerd` |
| 实机验证 | — | ✅ create/delete/scale | — |
